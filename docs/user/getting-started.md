# Getting started

Use the [scheduling README](../../README.md#run) for Python3.11+, private clone, local mock and CLI/Marimo setup. The application interprets public text with a real model and keeps synthetic identity local. Original generic poc_demo commands are retained for template tests, not scheduling acceptance.

Choose an API-returned slot, inspect the exact proposal and separately confirm. Ordinary yes and selection alone do not book. See [recovery](recovery.md).
